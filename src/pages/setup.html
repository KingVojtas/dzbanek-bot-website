Setup

All /setup subcommands need the Manage Server permission. Music and radio don’t need any setup, just a voice channel.

Subcommands

CommandWhat it does
/setup steamSets the channel for the daily Steam deals.
/setup epicSets the channel for Epic free games.
/setup welcomeSets the channel for welcome messages.
/setup goodbyeSets the channel for goodbye messages.
/setup kitchenSets the channel for the Kitchen Board. This one is never picked automatically.
/setup idle-radioOn by default: when the music queue runs out, the last radio station starts. Set it to off to make the bot leave instead.
/setup statusShows the server’s channels, Radio Night, and idle radio settings.
/setup disableTurns off Steam, Epic, welcome, goodbye, the Kitchen Board, Radio Night, or idle radio.

Automatic channel detection

If you don’t set a channel, Dzbanek looks for a text channel with one of these names.

The Kitchen Board always needs /setup kitchen.

Steam#steam #deals #steam-deals #slevy #akce
Epic#epic #free-games #epic-games #freebies
Welcome#welcome #arrivals #hello
Goodbye#goodbye #farewell #leaves

Permissions

The invite asks for these permissions (bitfield 3173440). It doesn’t ask for Administrator.

Manage Messages is used to delete the bot’s own previous Now Playing card and deal post. It isn’t used on anyone else’s messages.

FeaturePermissions
Music and radioConnect, Speak, View Channel
Steam and Epic postsView Channel, Send Messages, Embed Links, Manage Messages, Add Reactions
Welcome and goodbyeView Channel, Send Messages
Not requestedAdministrator

Server Members intent

Welcome and goodbye messages need the Server Members intent, which is turned on once for the bot in the Discord Developer Portal. If you use the public bot, it’s already on. If you host your own, you have to turn it on.

Self-hosting, Spotify keys, and YouTube cookies are explained in the bot’s repository.
