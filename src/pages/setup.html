Setup

Tell it where to post.

Every /setup command needs the Manage Server permission. Music and radio don’t need any setup, you just have to be in a voice channel.

/setup steam

Where the daily Steam deals go.

/setup epic

Where Epic free games go.

/setup welcome

Where welcome messages go.

/setup goodbye

Where goodbye messages go.

/setup kitchen

Where the Kitchen Board lives. This one never gets picked automatically.

/setup idle-radio

On by default. When the music queue ends, it switches to the last radio station instead of leaving. Set it to off if you’d rather it leave.

/setup status

Shows this server’s channels, Radio Night, and idle radio settings.

/setup disable

Turns off Steam, Epic, welcome, goodbye, the Kitchen Board, Radio Night, or idle radio.

Auto-detect

Channel names it finds on its own

If you skip /setup for something, Dzbanek looks for a text channel with one of these names.

The Kitchen Board always needs /setup kitchen.

Permissions

What it asks for

No admin rights. The invite asks for exactly these (bitfield 3173440), nothing more.

3173440

Manage Messages is only used to delete the bot’s own old Now Playing card and deal posts. It never touches anyone else’s messages.

Server Members intent

Welcome and goodbye messages need the Server Members intent, which gets switched on once in the Discord Developer Portal. If you use the public bot, it’s already on. If you host your own, you’ll need to turn it on yourself.

Self-hosting, Spotify keys, and YouTube cookies are all covered in the bot’s repo.
