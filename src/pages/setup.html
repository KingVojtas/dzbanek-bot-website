Setup

a cookbook for Discord

Tell it where to post

Every /setup command needs the Manage Server permission. Music and radio don’t need any setup, you just have to be in a voice channel.

Where things go

/setup steam
Where the daily Steam deals go.
/setup epic
Where Epic free games go.
/setup welcome
Where welcome messages go.
/setup goodbye
Where goodbye messages go.
/setup kitchen
Where the Kitchen Board lives, and where the Sunday postcard and Kitchen Wrapped go. This one never gets picked automatically.
/setup wishlist
Where Wishlist Radar pings people about their sales.
/setup idle-radio
On by default. When the music queue ends, it switches to the last radio station instead of leaving. Set it to off if you’d rather it leave.
/setup status
Shows this server’s channels, Radio Night, and idle radio settings.
/setup disable
Turns off Steam, Epic, welcome, goodbye, the Kitchen Board, Radio Night, or idle radio.
/setup wrapped-preview
This month’s Kitchen Wrapped so far, only for you.

What it asks for

No admin rights. The invite asks for exactly these permissions (bitfield 3263568).

3263568

Attach Files is for the pictures on the Kitchen Board, the Sunday postcard, and Kitchen Wrapped. Read Message History lets it find its own board and deal posts again after a restart; it only looks for its own.

Manage Channels is only for /textroom and /voiceroom, which only admins can run. Without it, everything else still works.

Server Members intent

Welcome and goodbye messages need the Server Members intent, which gets switched on once in the Discord Developer Portal. If you use the public bot, it’s already on. If you host your own, you’ll need to turn it on yourself.

Self-hosting, Spotify keys, and YouTube cookies are all covered in the bot’s repo.
